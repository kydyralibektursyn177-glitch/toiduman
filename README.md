# Үлкен той · 50 қонақ

Бөлек тәжірибелік нұсқа. Негізгі `main` тармағындағы клубқа әсер етпейді.

## Іске қосу

Node.js 24 орнатып, `npm ci`, содан кейін `npm start` орындаңыз. Windows-та `start-club.cmd` іске қосуға болады.

Басқару: http://127.0.0.1:3002/?admin=1

50 қонақ демосы: http://127.0.0.1:3002/?demo=50

OBS: http://127.0.0.1:3002/?capture=1 — 1080 × 1920. Ескі клубтың 3001 порты өзгермейді.

## Мүмкіндіктер

- Күлгін-алтын той залы, шарлар, ұлттық өрнекті кілем.
- 50 мультфильм кейіпкері бір уақытта. Бөлшектер InstancedMesh арқылы топтасып салынады, GLB жүктелмейді.
- Кіру және чат сыйлықсыз қосады. Би уақыты: 60 секунд; сыйлық уақытты ұзартады.
- Адамның аты мен чат бұлты, экранда соңғы хабар.
- 50 орын толғанда жаңа адам кезекке түседі; орын босағанда шығады. Кезек шегі: 300.
- Камера әуелде бүкіл алаңды көрсетеді. Басқарудан адамға жақындау режимін таңдауға болады.
- Той атауын өзгерту бір браузердің OBS бетіне де сақталады.
- Тікелей TikTok байланысы tiktok-live-connector арқылы. TikTok-тың серверлік шектеулері әлі қолданылуы мүмкін.

## Render

Осы нұсқаны тек бөлек Web Service ретінде іске қосыңыз. Branch: `wedding-50`; build: `npm ci`; start: `npm start`; `NODE_VERSION=24` және `ADMIN_KEY` орнатыңыз. Бұрынғы сервис тармағын өзгертпеңіз.
